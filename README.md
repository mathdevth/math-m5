# คณิตศาสตร์ ม.5 (เว็บประกอบการเรียน ภาคเรียนที่ 1–2)

จัดทำโดย ครูคุ้ม อชิตพล บุณรัตน์ — เพื่อการศึกษา ใช้ร่วมกับหนังสือเรียน
เทอม 1: หน่วยที่ 1 เลขยกกำลัง · หน่วยที่ 2 ฟังก์ชัน
เทอม 2: หน่วยที่ 3 ลำดับและอนุกรม · หน่วยที่ 4 ดอกเบี้ยและมูลค่าของเงิน

## นำขึ้น GitHub Pages
1. สร้าง repository ชื่อ `math-m5` (Public)
2. Add file → Upload files → ลาก index.html, config.json และโฟลเดอร์ worksheets → Commit changes
3. Settings → Pages → Branch: main, /(root) → Save
4. เว็บอยู่ที่ https://ชื่อผู้ใช้.github.io/math-m5/
5. อัปเดตครั้งต่อไป อัปโหลดเฉพาะ index.html (อย่าทับ config.json)

## เปิดระบบล็อกอิน (Firebase โปรเจกต์เดียวกับ ม.1 และ ม.3)
1. config.json: คัดลอก `"firebase": {...}` จาก config.json ของเว็บ ม.1 หรือ ม.3 มาวางแทน `null` แล้ว Commit
2. Authorized domains: อยู่โดเมนเดียวกัน (ชื่อผู้ใช้.github.io) ไม่ต้องทำอะไร
3. Firestore → Rules: ลบของเดิม วางทั้งไฟล์ firestore.rules (ใช้ได้ทั้ง ม.1 ม.3 ม.5) → Publish
4. เข้าเว็บ ม.5 ด้วยอีเมลครู → แดชบอร์ดครู → แท็บ “สร้างบัญชี” วางรายชื่อ ม.5 → พิมพ์ใบแจ้งรหัส
5. นักเรียนล็อกอินด้วยเลขประจำตัว + รหัส (บัญชีแยกจาก ม.1 และ ม.3 · อีเมลภายในคือ เลขประจำตัว@students.m5math.app)
6. ลืมรหัส: Authentication → Users ค้นหา `เลขประจำตัว@students.m5math.app` ลบ แล้วลบเอกสารใน m5students แล้วสร้างใหม่

## เปิด/ปิดเฉลยแบบฝึกหัด
- ทางที่ง่ายที่สุด: แดชบอร์ดครู → แท็บ “เปิดเฉลย” ติ๊กแล้วกดบันทึก (เก็บใน Firestore settings/m5)
- หรือแก้ config.json: "1.1", "1.2", "1.3" (เลขยกกำลัง) · "2.1", "2.2", "2.3ก", "2.3ข", "2.4", "2.5" (ฟังก์ชัน) · "3.1ก", "3.1ข", "3.1ค", "3.1ง" (ลำดับ) · "3.2ก", "3.2ข", "3.2ค" (อนุกรม) · "4.1", "4.2", "4.3" (ดอกเบี้ยและมูลค่าของเงิน)
  ตัวอย่าง `"openAnswers": ["3.1ก", "3.1ข"]` (ถ้าบันทึกจากแดชบอร์ดแล้ว ค่าในแดชบอร์ดจะใช้แทน config.json)

## ตัวนับผู้เข้าชม
